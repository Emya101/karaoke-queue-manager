# Karaoke Queue Manager

A simple command-line Python application for managing a karaoke queue.

Built as a hands-on project to practice core Python fundamentals and working with mutable data structures.

## Features

- View the current karaoke queue
- Add a singer and song
- Remove a singer
- Move a singer to the top of the queue
- Advance to the next singer
- Handle invalid position input
- Run continuously until the user quits

## Python Concepts Practiced

- Functions and parameters
- Lists and tuples
- Loops and conditionals
- User input
- Tuple unpacking
- `enumerate()`
- List methods such as `append()`, `pop()`, `insert()`, and `remove()`
- Exception handling with `try` / `except`
- String formatting with f-strings
